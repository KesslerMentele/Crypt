# Crypt - Fork of Hazel Game Engine

## Overview
Crypt is a personal fork of the [Hazel Game Engine](https://github.com/TheCherno/Hazel), originally developed by TheCherno. 
This project is aimed at learning game engine design and for use in private projects. 
It inherits the Apache License 2.0 from the original Hazel engine, adhering to its terms and conditions.
